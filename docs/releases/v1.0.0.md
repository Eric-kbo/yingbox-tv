# 映匣 YingBox TV v1.0.0

首个公开版本：在 Android 电视上浏览和播放电脑、NAS 或 WebDAV 目录中的照片、GIF 和视频。

## 下载与安装

1. 下载附件 **YingBoxTV-1.0.0.apk**。`Source code` 是开发源码，安装请选择 APK。
2. 将 APK 复制到 U 盘或电视可访问的位置，在电视文件管理器中打开。
3. 若系统提示不允许安装外部应用，允许该文件管理器安装应用后重试。
4. 打开应用列表中的「映匣」，选择「先体验一下」离线试用，或选择「添加源」连接自己的媒体目录。

要求 **Android 6.0 / API 23 或以上**，支持 `armeabi-v7a`、`arm64-v8a`、`x86_64`，一个 APK 包含三个架构。三星 Tizen、LG webOS 等非 Android 系统不能安装。APK 约 164 MiB，包含原生 LibVLC 播放库。

附件 `SHA256SUMS.txt` 提供 APK 和安装说明的 SHA-256 校验值。完整源码可从本版本的 `Source code` 下载，构建方法见仓库 README。

## 功能

- 支持 SMB 2/3、WebDAV，保存多个来源及必要的登录信息。
- 浏览照片、动画 GIF 和视频，按名称自然排序，支持照片 / 视频筛选。
- 遥控器操作：方向键选择，确认键打开，返回键返回；全屏 ↑ / ↓ 切换媒体。
- 视频确认键暂停 / 继续，← / → 跳转 10 秒，并记住播放位置。
- 照片确认键开启 / 停止每 7 秒切换的幻灯片。
- 内置离线演示媒体；来源设置本机保存，密码通过 Android Keystore 加密。

连接示例：SMB 使用 `smb://192.168.1.10/Photos`，WebDAV 使用 `https://example.com/dav/Photos/`。普通网页和网盘分享链接不能作为 WebDAV 目录。

## 验证与兼容范围

正式构建、6 项 JVM 协议测试和 Android Lint 检查通过；Lint 为 0 错误，有非阻塞警告。APK 正式签名、ZIP 对齐及 64 位原生库 16 KB LOAD 对齐已验证。

已有 Android TV x86_64 模拟器验证：6 项仪器测试通过，覆盖 SMB / WebDAV 认证、中文路径、随机读取、多来源管理、遥控器操作和多种视频格式解码。

实体电视、ARM 设备、真实公网 WebDAV、超大相册及 4K / HDR 影片尚未完成验证。HEIC / AVIF 依赖电视系统解码，视频兼容性与流畅度取决于内部编码、电视硬件和网络。

本版本不支持相机 RAW / TIFF、DLNA 发现、网盘 OAuth 登录、外挂字幕或字幕 / 音轨选择界面。

应用包名为 `com.localtv.viewer`，应用版本为 `1.0.0`。此安装包沿用本项目原有正式签名，可覆盖安装同签名版本。
