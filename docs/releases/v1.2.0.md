# 映匣 YingBox TV v1.2.0

本次发布包含 1.1.0 的浏览与配对改进，以及 1.2.0 的播放、缓冲和照片兼容性修复。可直接从 1.0.0 覆盖升级。

## 下载与安装

1. 下载附件 **YingBoxTV-1.2.0.apk**，约 185 MiB。
2. 复制到 U 盘或电视可访问的位置，在电视文件管理器中打开并安装；如有提示，允许该文件管理器安装外部应用。
3. 在应用列表打开「映匣 LocalTV」。首次使用可选择「先体验一下」，或添加自己的 SMB / WebDAV 媒体源。

需要 **Android 6.0 / API 23 或以上**的电视或电视盒子；同一 APK 支持 ARM 32 位、ARM 64 位及 x86_64。三星 Tizen、LG webOS 等非 Android 系统不能安装。

安装包沿用原正式签名，包名 `com.localtv.viewer`，版本号 `1.2.0`、版本代码 `3`。直接覆盖安装可保留媒体源、加密密码和浏览偏好；无需先卸载旧版。

`INSTALL.md` 为安装与版本说明，`SHA256SUMS.txt` 提供所有发布附件的 SHA-256 校验值。开发者可下载 `YingBoxTV-1.2.0-source.zip` 或 GitHub 自动生成的源码包；源码构建方法和第三方许可证随仓库提供。

## 播放与照片改进

- 常用视频使用 Media3 原生硬件解码和 SurfaceView，识别并传递 HDR / Dolby Vision 色彩元数据；旧格式保留 LibVLC 兼容模式。
- 视频直接读取 SMB / WebDAV，播放与浏览连接分离；SMB 增加 1 MiB 有界预读，原生播放器媒体缓冲目标上限 64 MiB。
- 视频播放期间暂停新的缩略图生成及相邻照片预加载，减少读取竞争。
- HEIC / HEIF 优先使用平台解码，失败后在 Android 7+ 的 ARM 设备尝试软件回退；改进较大分块图像和高位深照片支持，AVIF 也有软件回退。
- 增加已缓冲进度、跳转预览和连续按键合并。菜单可选择音轨、内嵌字幕、画面比例及播放引擎，并查看读取与解码统计。

## 浏览与添加源改进

- 五列媒体网格，默认按文件时间从新到旧排列，支持名称排序及每个来源的排序偏好。
- 可按照片 / 视频、文件名、年份 / 月份、最近时间及扩展名组合筛选，并按月定位。筛选作用于当前文件夹。
- 目录索引与筛选在后台执行，改善大目录浏览和遥控器焦点定位。
- 添加源默认显示二维码，手机与电视在同一网络时，可扫码填写 SMB / WebDAV 地址和登录信息，无需安装手机应用；也可用遥控器填写。

## 验证与兼容范围

发布构建、18 项 JVM 测试和 Android Lint 检查通过；Lint 为 0 错误，保留非阻塞警告。APK 正式签名、ZIP 16 KiB 页对齐和 64 位原生库 16 KiB LOAD 对齐已核验。

本版本已有 13 项 Android TV 模拟器测试、4 项 ARM 电视回归测试和最后一次界面调整后的单项播放回归记录。在一台 Android 14 小米 ARM64 电视上验证了 4K 60fps Dolby Vision / HLG 视频及 HEIC 图片；具体记录见仓库 `QA-1.2.0.md`。

视频兼容性与 HDR 显示仍取决于电视硬件和厂商实现；AV1 视频尚未实机验证。x86_64 的 HEIC 使用平台解码，不能等同于 ARM 软件回退能力。HDR 照片目前以 SDR 位图显示，不保留增益图。软件 HEIC 解码限制单个输入 64 MiB、图像 1 亿像素，并按显示尺寸缩放。

扫码添加使用临时局域网 HTTP 页面，请在可信网络内使用；远程 WebDAV 建议使用 HTTPS。当前不支持相机 RAW / TIFF、DLNA 发现、网盘 OAuth 登录或外挂字幕管理。
